# JS Recipe Calculator

An application coded using basic HTML, CSS, and JavaScript to calculate recipe portions using the recipe conversion formula. Built using a mobile-first approach.

## Technologies
- HTML
- CSS
- JavaScript (Vanilla)
- Vite

## How to Use
1. Fill out the form with your recipe name, all your required ingredients, the original portion size, and your desired scale.
2. Use '+ Add Ingredient' to add a blank ingredient row.
3. Use 'Resize Recipe' to get the ingredients needed for your desired scale and the original scale for comparison.
4. Use 'Print' to print both cards.
5. Use 'Clear' to reset all form fields.

** Fractions currently aren't supported; please enter whole numbers or decimals. **

---

### From left to right, each row has:
1. Quantity: Enter a positive integer (> 0)
2. Measurement: Dry (flour, salt, etc.) or Liquid (water, milk, etc.)
3. Ingredient Name: Enter the ingredient's name
4. 'X': Delete; clears all content of the row
